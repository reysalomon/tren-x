# Голосовые фразы живой камеры

23 фраз на каждом языке: казахские — в `kk/`, русские — в `ru/`. Имена файлов — строго как в таблице.
Если файла нет, сайт говорит синтезом речи браузера (русский есть почти везде, казахский — редко).

Все фразы записаны в ElevenLabs одним голосом: стандартный голос **Callum**
(`N2lVS1w4EtoT3dr4eOWO`), модель `eleven_v4`. Тексты берутся из `web/i18n.js` (ключи `say_...`).

Записать недостающие или перезаписать все (ключ ElevenLabs — в `~/.elevenlabs_key` или `ELEVENLABS_API_KEY`):

```bash
python scripts/make_voice.py --list                                         # чего не хватает
python scripts/make_voice.py --voice N2lVS1w4EtoT3dr4eOWO --model eleven_v4   # дозаписать
python scripts/make_voice.py --all --voice ID --model ID                    # перезаписать все другим голосом
```

Новую фразу нужно также добавить в список `CLIPS` в `web/live.js`.
