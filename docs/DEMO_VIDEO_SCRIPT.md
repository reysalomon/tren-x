# TREN-X — демо-видео сценарийі (2–3 минут)

Видеоны телефонның экран жазбасымен түсіруге болады (экран + дауыс). Жалпы ұзақтығы — шамамен 2 мин 40 с.
«Экранда» бағаны — не көрсету керек, «Айтатын сөз» бағаны — не айту керек.

## Дайындық

1. Компьютерде серверді қос: `.venv/bin/uvicorn server:app --host 0.0.0.0 --port 8000`
2. Туннельді қос: `cloudflared tunnel --protocol http2 --url http://localhost:8000` — шыққан сілтемені телефонда аш.
3. Телефонды 2–3 метрге, бүйірден қоятын орын дайында. Жарық жақсы болсын.
4. Тіл — қазақша (ҚАЗ).

## Кеңестер

- Тікелей камера бөлігін бір дубльмен түсір: қате қайталауды әдейі анық жаса (таяз отыр немесе қатты еңкей).
- Интернет нашар болса, тікелей камераның орнына алдын ала түсірілген видеоны жүктеп көрсет («Видео жүктеу»).
- Уақыт асып кетсе, тіл ауыстыру бөлігін (2:10–2:25) қысқарт.
