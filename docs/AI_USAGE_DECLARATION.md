# 1. Қандай AI құралдары қолданылды

| Құрал | Модель | Не үшін |
|---|---|---|
| Claude Code (Anthropic), терминалдағы CLI-ассистент | Claude Opus | Студенттің нұсқауы бойынша код, тесттер, құжаттама, есеп және слайдтар жазу, жөндеу, қазақ тіліне аудару |
| [басқа құралдар болса, мысалы ChatGPT — көрсету немесе жолды өшіру] | | |

AI **қосымшаның ішінде қолданылмайды**: жұмыс істеп тұрған бағдарламада LLM немесе сыртқы AI API
шақырулары жоқ. Курстың барлық төрт AI әдісі (агент, HMM, классификатор, нейрожелі) жобаның өз
кодымен жұмыс істейді. Дайын MediaPipe Pose моделі тек буындар координаттарының датчигі ретінде
қолданылады және бұл барлық құжаттарда көрсетілген.

# 2. AI-ассистент не істеді

- **Код:** `formcoach/` модульдері кодының көп бөлігі (белгілер, Витерби алгоритмі бар HMM, агент,
  классификатор, NumPy-дағы MLP, белгілеу, қосымша оқыту), мобильді сайт (`server.py` сервері және
  `web/` интерфейсі, қазақша/орысша нұсқалары), Streamlit интерфейсі `app.py` және `scripts/` ішіндегі скрипттер.
- **Тесттер:** 67 автоматты тест.
- **Құжаттар:** README, Technical Report, слайдтар, осы декларация және Contribution Statement
  жобалары; олардың қазақша аудармасы.
- **Орта:** баптау (Python 3.12, жүйелік кітапханалар), демо режимнің скриншоттары.
- **Ұсыныстар:** жобаның силлабус апталарына сәйкестігі, әділ тексеру тәсілі (клиптер бойынша
  GroupKFold, leave-one-video-out), белгілерді таңдау.

# 3. Студент не істеді

- **Шешімдер:** жоба тақырыбын таңдады және «MediaPipe — датчик + курстың 4 тақырыбы өз кодымен»
  сызбасын қабылдады. Ассистентке тапсырма беріп, әр қадамда шешім қабылдады: қандай тақырыптарды
  жасау, қандай ретпен, нені жариялау, қосымшаның қандай түрі болуы керек (дүкендегі қосымша орнына
  мобильді сайт), құжаттар мен сайттың тілі.
- **Деректер:** өз отырып-тұру видеоларын түсіріп, қосымшада қайталауларды белгіледі. Жинау жалғасуда.
- **Нақты видеода тексеру:** қосымшаны өз видеосында және телефонда іске қосып, шындықпен
  сәйкессіздіктерді тапты. Мысалы, табан кадрдан шығып кетті, өз видеосындағы қателер датасеттегіден
  жеңілірек. Осы бақылаулар бойынша код түзетілді.
- **Кодты талдау:** [өз сөзіңмен сипатта: өзің нені талдадың және өзгерттің — мысалы, «Витерби
  алгоритмі мен backprop-ты кодтағы формулалар бойынша талдадым», «агент шектерін өзгерттім»].
- **Қорғау:** қорғауды және демо-видеоны дайындайды.

# 4. AI нәтижелері қалай тексерілді

- Барлық код автоматты тесттермен қамтылған. Негізгі алгоритмдер үшін математикалық тексерулер бар:
  Витерби бағасы толық ықтималдықтан аспайды, backprop градиенттері сандық градиенттермен сәйкес келеді.
- Модельдердің метрикалары модель көрмеген деректерде алынған: датасеттің test бөлігіндегі басқа
  адамдар, кросс-валидациядағы бөлек клиптер. Есептегі сандар қолмен жазылмаған, скрипттердің
  сақталған есептерінен алынған.
- Шектеулер тікелей көрсетілген: HMM мен агент метрикалары синтетикада алынған, өз видеоларымыз әзірге аз.
- Қосымша студенттің нақты видеосында және телефонында тексерілді.

# 5. Мәлімдеме

Мен жобаның барлық бөліктерінің құрылымын түсінемін және қорғауда агенттің, HMM-нің (Витерби
алгоритмі және тура алгоритм), GroupKFold тексеруі бар классификатордың және қатені кері тарату
әдісімен оқытылатын нейрожелінің қалай жұмыс істейтінін түсіндіре аламын. Жобаның және тапсырылған
барлық материалдардың мазмұнына мен жауап беремін.
